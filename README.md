# Anthony Wyse Portfolio

A static professional portfolio focused on AWS network deployment, infrastructure delivery, and security development.

## Pages

- `index.html`: introduction and LinkedIn contact
- `work.html`: professional experience
- `skills.html`: infrastructure capabilities and security development
- `certifications.html`: certifications and training links
- `education.html`: formal education and learning profiles

The repository also includes standalone introductory security learning pages. They are not presented as professional case studies.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` in the repository directory and visit `http://localhost:8000`.

## Updating content

The site uses plain HTML and a shared `styles.css` file. Update the relevant HTML page and check links, mobile layout, and keyboard navigation before publishing. Keep job dates and titles aligned with the current résumé and LinkedIn profile.
